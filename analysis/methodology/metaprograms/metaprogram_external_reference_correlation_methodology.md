# Parse External Reference Metaprogram Correlation Methodology

Script: `analysis/metaprograms/parse_metaprogram_external_reference_correlation.R`

Status: active terminal cross-dataset comparison workflow.

## Purpose

This script compares selected Parse metaprograms to scATLAS and PDO-pipeline metaprograms using both gene-set Jaccard overlap and UCell expression correlation.

## Inputs

- `parse_outs/Auto_parse_metaprograms/Auto_parse_MP_outs_default.rds`
- `parse_outs/Auto_parse_metaprograms/Auto_parse_UCell_scores_filtered_nMP<k>.rds`
- `parse_outs/cell_states/Auto_parse_scATLAS_UCell_scores.rds`
- `parse_outs/cell_states/Auto_parse_PDOpipeline_UCell_scores.rds`
- scATLAS metaprograms: `/rds/general/project/tumourheterogeneity1/ephemeral/scRef_Pipeline/ref_outs/Metaprogrammes_Results/geneNMF_metaprograms_nMP_19.rds`
- PDO-pipeline metaprograms: `/rds/general/project/tumourheterogeneity1/ephemeral/PDOs_Pipeline/PDOs_outs/Metaprogrammes_Results/geneNMF_metaprograms_nMP_13.rds`

## Processing

1. Load selected Parse MP genes and UCell scores.
2. Filter negative-silhouette and low-coverage Parse MPs.
3. Load scATLAS metaprograms and order them by the scATLAS state grouping.
4. Load scATLAS UCell scores generated by the state workflow.
5. Load PDO-pipeline metaprograms and order them by PDO state grouping.
6. Load PDO-pipeline UCell scores generated by the state workflow.
7. Compute Parse-vs-reference Jaccard matrices.
8. Compute Parse-vs-reference Spearman correlation matrices.
9. Save four PDFs: Jaccard and correlation against scATLAS and PDO.

## Outputs

Output tiers:

- `figures`: `Auto_parse_mp_jaccard_vs_scATLAS.pdf`
- `figures`: `Auto_parse_mp_jaccard_vs_PDO.pdf`
- `figures`: `Auto_parse_mp_correlation_vs_scATLAS.pdf`
- `figures`: `Auto_parse_mp_correlation_vs_PDO.pdf`
- `logs`: `parse_outs/logs/run_summaries/parse_metaprogram_external_reference_correlation_*.txt`

## Downstream Use

Terminal comparison workflow. It depends on cell-state UCell caches but is not itself used downstream.
