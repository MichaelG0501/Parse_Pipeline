# High-Resolution Metaprograms Heatmap Methodology

Script: `analysis/publication/parse_highres_metaprogram_heatmap.R`

## Purpose

This script generates a publication-ready similarity heatmap of the high-resolution metaprograms, matching the "many nMP" splitting strategy originally used in the legacy comparison filter (`legacy_parse_highres_mp_t2t4_comparison_filter.R`).

The primary challenge when visualizing a highly fragmented similarity matrix (e.g., `nMP = 117`) is that default heatmap wrappers like `GeneNMF::plotMetaPrograms` (which uses `pheatmap` under the hood) create large graphical gaps between clusters. When there are over 100 splits, these gaps occupy the vast majority of the plot area, causing the heatmap to appear as a solid white block.

This script solves this issue by explicitly using `ComplexHeatmap::Heatmap` and strictly defining the gap size to a minute `0.2 mm`. This preserves the visual tree structure and block segregation without sacrificing data visibility.

## Inputs

- `parse_outs/Auto_parse_metaprograms/Auto_parse_geneNMF_outs.rds`: Used solely to determine the total number of underlying NMF programs and infer the target `nMP` (`nMP = total_nmf_programs / 2`).
- `parse_outs/Auto_parse_highres_metaprogram_trends/Auto_parse_highres_geneNMF_metaprograms_nMP<k>.rds`: The cached `geneNMF.metaprograms` result generated by the legacy high-res filter for the target `nMP`.

## Processing

1. Calculates `nMP` based on the saved `GeneNMF` output dimensions.
2. Loads the cached high-resolution metaprograms object.
3. Extracts the cosine similarity matrix, the hierarchical clustering tree, and the `cutree` block assignments.
4. Ensures similarity values are strictly bounded between `[0, 1]`.
5. Maps block assignments to the correct dendrogram-ordered factor levels.
6. Generates a `ComplexHeatmap::Heatmap` configured with:
    - Pre-computed `tree` for row and column clustering.
    - `row_split` and `column_split` using the factor levels to partition the matrix.
    - `row_gap` and `column_gap` set to `0.2 mm`.
    - No titles on the internal slices to prevent overlapping text, relying instead on a side color annotation bar.

## Outputs

Output directory: `parse_outs/publication/highres_metaprogram_heatmap/figures/`

- `highres_metaprogram_heatmap.pdf`: The vector PDF graphic suitable for publication.
- `highres_metaprogram_heatmap.png`: High-resolution PNG raster graphic.
- `parse_outs/logs/run_summaries/parse_highres_metaprogram_heatmap_*.txt`: Execution trace log.

## Downstream Dependencies

None. This is a terminal figure generation script.
